# Processed data

This directory contains the processed data generated by the final NEW_V1 analysis run.

- `mp_elastic_clean.csv`: cleaned elastic-property records after the reported filtering steps.
- `mp_features.csv`: target and 138 generated composition descriptors.
- `composition_groups.csv`: reduced-formula grouping information used for grouped evaluation.
- `cleaning_report.json`: machine-readable data-cleaning summary, when available.
- `run_manifest.json`: final-run configuration and metadata, when available.

The raw Materials Project JSON export and API credentials are not included.
